# Собственный Java Launcher — прототип 0.1

Нативный Android-интерфейс, написанный в этом репозитории. Не PojavLauncher,
не ссылка на чужой APK и не запуск Bedrock. **Minecraft пока НЕ запускается.**

## Реализовано
- Выбор release-версий из официального каталога Mojang.
- Загрузка JSON версии с проверкой SHA-1 из каталога.
- Загрузка client.jar с проверкой размера и SHA-1, временный файл до проверки.
- Работа сети вне UI-потока, таймауты, сообщения об ошибках, повторная загрузка.
- Только HTTPS и разрешённые домены Mojang, без произвольных URL и редиректов.
- Хранение в закрытом каталоге приложения без разрешений на общее хранилище.

## Не реализовано — до готового лаунчера
1. Microsoft OAuth (без сбора паролей), Xbox/Minecraft Services и проверка лицензии.
2. Загрузка библиотек, assets и native-зависимостей по описанию версии.
3. Android-совместимая Java-среда: desktop-JVM на Android не работает.
4. Нативный графический слой, GLFW/LWJGL-совместимость и сенсорный ввод.
5. Запуск процесса, журнал ошибок, тесты на физических ARM64-устройствах.

Эти пункты обязательны: скачанный client.jar сам по себе не делает игру рабочей.
Авторизация и загрузка официальных ресурсов требуют доступа к серверам Microsoft/Mojang.
Сетевой доступ среды разработки ограничен: реальный каталог здесь не проверен.

## Сборка
GitHub Actions → Build APK → артефакт JavaLauncher-prototype.
Прототип публикуется отдельно в prerelease `java-launcher-prototype`.
Старый релиз Windows11.apk не заменяется. Используются прежние package ID и ключ:
установка прототипа поверх Windows11.apk заменит главный экран на Java Launcher.

## Проверки
GitHub Actions компилирует Android APK. `npm ci && npm test` проверяет только
сохранённую старую web-оболочку, а не новый нативный лаунчер.
