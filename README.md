# Java Launcher 0.5 — единое приложение

Версия 0.5 убирает дополнительный стартовый экран 0.4. Нажатие на иконку сразу
открывает встроенное меню аккаунта, версии и игры. **Никакой отдельный PojavLauncher
или Bedrock не устанавливается и не запускается.** Java runtime, графика и игровой
Activity включены в тот же APK (`com.arena.win11`). Изолированный процесс `:game`
принадлежит этому же приложению, а не другому пакету.

Это производная сборка открытого PojavLauncher с нашим build overlay, а не независимо
написанный игровой движок. Авторы и LGPL-лицензия сохранены.

- Сборка: `.github/workflows/playable-apk.yml` → Build Java launcher with game engine.
- Релиз: `java-launcher-0.5`, APK `JavaLauncher-0.5.apk`.
- Изменения к закреплённым исходникам: `scripts/prepare_engine.py`.
- Лицензии и пересборка: `launcher-engine/NOTICE.md`.
- Инструкция и границы проверок: `launcher-engine/RELEASE.md`.

Можно обновить поверх 0.4: package ID, подпись и каталоги движка не меняются.
В APK нет файлов Minecraft; upstream-проверки авторизации не отключаются.
Для первого теста рекомендуется Vanilla 1.12.2 / Java 8 / GL4ES.
**Запуск мира на физическом ARM-телефоне ещё не проверен.**

Проверки: Python unit-тесты overlay, содержимое APK, Android x86_64 smoke-тест:
запуск через launcher entry → игровое меню в этом же пакете и распаковка Java 8,
причём сторонний PojavLauncher в эмуляторе не установлен. Это не тест игрового мира.

## Старый самостоятельный загрузчик 0.3 (сохранён для истории)

Код под `android/` — прежний прототип загрузчика без игрового движка. Старая workflow
`apk.yml` собирает именно его. Это не та же сборка, что интеграция 0.5 выше.
Скачанные им файлы сохраняются при обновлении, но не мигрируются в каталоги движка.

# Собственный Java Launcher — прототип 0.3

Нативный Android-интерфейс, написанный в этом репозитории. Не PojavLauncher,
не ссылка на чужой APK и не запуск Bedrock. **Minecraft пока НЕ запускается.**

## Новое в 0.3
- Необязательная загрузка Java-библиотек и content-addressed assets с официальных серверов.
- Проверка SHA-1 и размера; ранее проверенные файлы не скачиваются повторно.
- Отмена загрузки (сетевая операция может завершаться до 30 секунд).
- Прогресс по этапу и файлу; проверка свободного места, защита от выхода пути за каталог.
- Кеш каталога при сетевой ошибке, запоминание выбранной версии.
- Копирование диагностики: версия приложения, Android, ABI, этап и сетевой журнал.
  Журнал не содержит ник, токены или пароли. Старые записи сокращаются при 128 КБ.
- Данные можно догрузить повторным нажатием; это не побайтовое продолжение .part-файла.

Загрузка библиотек и ресурсов выключена по умолчанию: она может требовать гигабайты.
Включите галочку перед загрузкой клиента. Пока приложение работает, экран остаётся включён.
Это foreground-прототип: Android может остановить загрузку в фоне. Повтор проверит файлы.
**Старые virtual/map_to_resources assets и версии без assetIndex пока не поддерживаются.**
Библиотеки отбираются по базовым Linux-правилам; desktop-native classifiers не загружаются:
они не подходят Android. Это подготовка файлов, а не совместимая игровая установка.

## Реализовано
- Локальный профиль без входа Microsoft: ник (3–16 символов A–Z, a–z, 0–9, _) и детерминированный офлайн-UUID.
- Сохранение ника между запусками; профиль не является лицензией или авторизованной сессией.
- Профиль пока не используется игровым процессом: запуск ещё не реализован.
- Выбор release-версий из официального каталога Mojang.
- Загрузка JSON версии с проверкой SHA-1 из каталога.
- Загрузка client.jar с проверкой размера и SHA-1, временный файл до проверки.
- Работа сети вне UI-потока, таймауты, сообщения об ошибках, повторная загрузка.
- Только HTTPS и разрешённые домены Mojang, без произвольных URL и редиректов.
- Хранение в закрытом каталоге приложения без разрешений на общее хранилище.

## Не реализовано — до готового лаунчера
1. Microsoft OAuth (без сбора паролей), Xbox/Minecraft Services и проверка лицензии.
2. Android-совместимые native-зависимости и размещение legacy-ресурсов.
3. Android-совместимая Java-среда: desktop-JVM на Android не работает.
4. Нативный графический слой, GLFW/LWJGL-совместимость и сенсорный ввод.
5. Запуск процесса и тесты на физических ARM64-устройствах.

Эти пункты обязательны: скачанный client.jar сам по себе не делает игру рабочей.
Авторизация и загрузка официальных ресурсов требуют доступа к серверам Microsoft/Mojang.
Сетевой доступ среды разработки ограничен: реальный каталог здесь не проверен.

## Сборка
GitHub Actions → Build APK → артефакт JavaLauncher-0.3.
Прототип публикуется отдельно в prerelease `java-launcher-0.3`.
Старый релиз Windows11.apk не заменяется. Используются прежние package ID и ключ:
установка прототипа поверх Windows11.apk заменит главный экран на Java Launcher.

## Проверки
GitHub Actions запускает unit-тесты ника/UUID, правил библиотек, путей, ресурсов и проверки хешей и компилирует Android APK. `npm ci && npm test` проверяет только
сохранённую старую web-оболочку, а не новый нативный лаунчер.
