# Windows 11 — веб-клон + APK (v4)

Максимально близкая к оригиналу Windows 11 рабочая среда, написанная на чистом
HTML/CSS/JS (без фреймворков), упакованная в нативное Android-приложение (WebView).

## Новое в v4

- **Обои из своих фото** — Параметры → Персонализация → «Фото с устройства»:
  миниатюры фото из DCIM/Pictures телефона (создаются миниатюры на Java-стороне,
  чтобы не грузить полные файлы), тап — и фото стало фоном рабочего стола.
  В браузере — кнопка «Выбрать файл…». Работает и «Сделать фоном» в Фотографиях
- **Панель задач как в оригинале** — погода-кружок внутри таблетки поиска
  (клик → панель виджетов), колокольчик уведомлений справа от часов,
  формат даты 25-11-2026, закреплены только Проводник и Параметры
- **Панель виджетов** — «Привет, Пользователь», карточки погоды, часов и советов
- **Календарь как в оригинале** — компактный: дата сверху, свёртываемые уведомления,
  «Ноябрь 2026 г.», дни недели одной буквой, сегодняшний день серым кружком
- **Быстрые действия как в оригинале** — Wi-Fi, Интернет, Bluetooth, Обмен рядом,
  Тема (светлая/тёмная одним нажатием), Доступность; громкость + яркость; батарея + шестерёнка
- **Поиск в две колонки** — «Быстрый поиск» с цветными значками слева,
  «Советы» справа, живые результаты при вводе
- Значки рабочего стола с **стрелками ярлыков**, первый значок — «Этот ПК»

## Новое в v3

- **Встроенная клавиатура** — своя сенсорная клавиатура в стиле Windows Touch Keyboard:
  русская/английская раскладка, символы &123, Shift, ⌫, ⏎, кнопка в трее.
  Системная клавиатура Android полностью отключена (NoImeWebView) —
  никакого «раздувания» экрана и «дырок», система всегда занимает весь экран
- **Реальные характеристики девайса** в «Параметры → Система → О системе»:
  модель телефона, процессор (ядра/архитектура), ОЗУ, разрешение экрана,
  свободное место, версия Android + переименование устройства
- **Фиксы на телефоне (landscape ~350px высоты)**: Пуск, календарь, быстрые
  действия и поиск автоматически переходят в компактный режим и прокручиваются —
  календарь больше не налезает на панель задач
- **Кэш WebView отключён** — всегда свежие файлы, старый JS не подмешивается
- Сайдбары Проводника и Параметров сжимаются по ширине ОКНА (а не экрана)
- Процент батареи всегда виден в трее
- Автотест (jsdom): Пуск, все 17 приложений, клавиатура — проверяются на каждый коммит

## Новое в v2

- **Реальные файлы телефона** — Проводник показывает Download, DCIM, Documents и др.
  через Java-мост `AndroidBridge`; фото открываются в «Фотографиях», текст — в Блокноте
- **Батарея как на телефоне** — страница «Питание и батарея»: заряд, оставшееся время,
  график за 24 часа, расход по приложениям, режимы питания, экономия заряда.
  На Android — настоящий уровень заряда через BatteryManager
- **Диспетчер задач** — процессы, ЦП/память, «Снять задачу», вкладка «Производительность»
- **Фикс клавиатуры** — экран подгоняется под visualViewport: никакой «дырки» при вводе
- **Фикс календаря** — адаптивная ширина, выбор дня, «Очистить всё», кнопка «сегодня», свайп месяцев
- **Fluent-иконки** — Проводник, Edge, Store, Параметры, Фото, Калькулятор, Блокнот, Paint,
  Терминал, Погода, Часы, Медиаплеер перерисованы как в настоящем Windows 11
- **Настройки панели задач** — выравнивание по центру/слева, погодный виджет вкл/выкл
- **Процент батареи в трее**, живые часы каждую секунду
- Открытие приложения «по тапу» на сенсорных экранах (двойной клик на ПК)
- Edge: настоящая история вкладок (назад/вперёд), поиск из Параметров открывается в Edge

## Возможности

- **Загрузка → экран блокировки → рабочий стол** — как на настоящей Windows 11 (логотип, спиннер, время на локскрине)
- **Курсоры Windows** — стрелка, текстовый I-beam, «занятость» (custom PNG-курсоры)
- **Панель задач** — центрированные значки, погодный виджет слева, треи справа
  (Wi-Fi / звук / батарея), часы, кнопка «Показать рабочий стол»
- **Пуск** — поиск, «Закреплено» (6 в ряд), «Рекомендуем», «Все приложения» с буквами, питание (сон / выключение / перезагрузка — реально работают)
- **Быстрые действия** — Wi-Fi, Bluetooth, режим «в самолёте», экономия заряда,
  **ночной свет**, **ползунки яркости и громкости** (громкость реально меняет громкость звуков системы)
- **Календарь + уведомления** по клику на часы (рабочий календарь с перелистыванием месяцев)
- **Поиск** — отдельная панель с «лучшим соответствием» и поиском в Интернете
- **Представление задач** (Alt/Meta+Tab) — карточки открытых окон
- **Окна** — перетаскивание, изменение размера со всех сторон, свернуть/развернуть/закрыть,
  **Snap Layouts** — тяните окно к краю/верху экрана (половины и четверти), кнопка максимизации меняет вид
- **Рабочий стол** — значки, рамка выделения, перетаскивание значков с привязкой к сетке, контекстное меню (Вид, Сортировка, Обновить, Создать, Персонализация)
- **Microsoft Store** — главная с hero-баннером, категории, поиск, **страница приложения
  с рейтингом, отзывами и скриншотами, кнопка «Получить» с настоящим прогрессом загрузки
  и установкой**; библиотека с обновлениями и удалением приложений
- **Параметры** — Система (Дисплей: яркость, ночной свет, масштаб; Звук: громкость, тест;
  О системе: характеристики устройства и Windows), Bluetooth, Сеть и Интернет (список Wi-Fi сетей),
  **Персонализация (4 обои, светлая/тёмная тема, 8 акцентных цветов, прозрачность)**,
  Приложения (установленные, удаление), Учётные записи, Время и язык, Игры, Специальные возможности,
  Конфиденциальность, **Центр обновления Windows** (проверка обновлений с анимацией)
- **Приложения**: Проводник (дерево папок, диски C:/D:, открытие .txt/.jpg/.mp3), Microsoft Edge
  (вкладки, адресная строка, поиск, локальные страницы), Блокнот (сохранение текста),
  Калькулятор (полнофункциональный), Paint (рисование на холсте), Фотографии (просмотр,
  «Сделать фоном»), Терминал (15+ команд: help, systeminfo, ping, shutdown…), Погода
  (8 городов, прогноз на неделю), Часы (мировое время), Медиаплеер (4 synth-трека,
  генерируются Web Audio), Задачи, Змейка, Сапёр
- Все настройки сохраняются в localStorage

## Как открыть

- Веб-версия: любой статический сервер из папки `www/` (например `python3 -m http.server -d www`)
- Android: APK собирается workflow-ом **Build APK** (`.github/workflows/apk.yml`) —
  артефакт `Windows11-APK` во вкладке Actions. Установка: скачать APK → открыть на телефоне → разрешить установку.

## Сборка APK

```bash
bash scripts/pack_assets.sh          # копирует www/ в android assets
cd android
gradle wrapper --gradle-version 8.9
./gradlew assembleDebug              # APK: app/build/outputs/apk/debug/app-debug.apk
```

Генерация собственного keystore: `python3 scripts/make_keystore.py` (требует `cryptography`).

## Структура

```
www/            веб-приложение (index.html, css, js, assets)
android/        Android-проект (WebView-обёртка, Kotlin)
scripts/        prep_media.py (ресурсы), make_keystore.py, pack_assets.sh
assets_src/     исходные обои (PNG)
```
