# Bedrock Launcher 1.0 — отдельный Android-проект

Собственный нативный лаунчер-компаньон, написанный на Kotlin с нуля. Не Java Edition,
не Pojav, не Windows/WebView и не копия игрового движка. **Кнопка «Играть» открывает
установленный Minecraft Bedrock (`com.mojang.minecraftpe`) отдельным приложением.**
Этот вариант согласован с пользователем. Minecraft устанавливается и приобретается
отдельно; никаких файлов игры, лицензий или аккаунтов в APK нет.

## Функции
- Определение наличия/версии официального пакета Minecraft и его запуск.
- Понятное сообщение, если игры нет, и ссылка на её страницу Google Play.
- Локальный список серверов: добавить, редактировать, удалить; IPv4, IPv6, IDN, порт.
- Передача `minecraft://?addExternalServer=...` именно пакету Minecraft. Это предложение
  добавить сервер, не гарантия прямого подключения. Подтверждение выполняется в игре.
- Импорт `.mcpack`, `.mcaddon`, `.mcworld` через системный выбор файла, до 512 МБ.
- Проверка расширения и непустого ZIP без распаковки. Временная копия в закрытом кеше,
  узкий read-only FileProvider, ClipData и временное разрешение чтения только получателю.
- Ошибки открытия, чтения и нехватки места отображаются в интерфейсе.
- Копирование диагностики (версия Android/ABI/игры и последний статус).

Список серверов не записывается в приватные каталоги Minecraft. Совместимость пака,
получение команды конкретной версией Bedrock и завершение импорта определяет игра.
Копии импортов старше 7 дней очищаются при следующей подготовке импорта; системный
Android также может очистить кеш. Исходные выбранные файлы не меняются.

## Безопасность / приватность
Нет запросов логина или пароля Microsoft, сетевых запросов самого лаунчера, аналитики,
доступа ко всему хранилищу или файлового сервера. Серверы хранятся локально в
SharedPreferences, резервное копирование Android отключено. Внешние операции явно
передаются Minecraft; единственная общая ссылка — HTTPS-страница магазина.
Диагностика копируется в буфер только по нажатию пользователя. Не импортируйте
неизвестные аддоны; ZIP-проверка не является антивирусом.

## Сборка
JDK 17, Android SDK 34, Gradle 8.9:

```sh
cd bedrock
gradle :app:testDebugUnitTest :app:assembleDebug
```

Сборка использует `../android/debug.keystore` из репозитория — это открытый
**development key**, не production-подпись. Application ID `com.arena.bedrock`,
Android 7.0+. Устанавливается отдельно, не заменяет прежний JavaLauncher.
Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions: `Build native Bedrock launcher`, workflow `bedrock-apk.yml`.
Релиз: `bedrock-launcher-1.0`, APK `BedrockLauncher-1.0.apk`.
Архив исходников в релизе включает этот проект, CI, smoke-скрипт и development key.

## Тесты и их границы
- JVM: валидация адресов/портов/имён, IDN, IPv6, безопасные имена и MIME импортов.
- Android smoke: настоящий лаунчер запускается без Minecraft и показывает понятную ошибку.
- Android instrumentation: сохранение серверов и recreation, ACTION_MAIN, deep link,
  URI-кодирование, передача читаемого content URI в другой UID с read-only grant.

Для последней группы есть `testgame/`: **маленький CI-only приёмник Intent**, не игра.
Он использует имя официального пакета только в чистом тестовом эмуляторе, чтобы
проверить контракт передачи. Он НЕ включён в релизный APK и не публикуется отдельно.
Не устанавливайте testgame на личный телефон или поверх настоящего Minecraft.
Тест импорта подаёт результат выбора документа в Activity напрямую, не автоматизирует
системный DocumentsUI. Это не проверка настоящего Bedrock, игрового мира или реального
Android-телефона. Такие проверки пока требуют установленной собственной копии игры.
