# Bedrock Launcher 1.1 — нативный Android-компаньон

Новый проект на Kotlin, без Pojav, Java Edition, WebView или Windows-оболочки.
Кнопка «Играть» открывает отдельно установленный Minecraft Bedrock (`com.mojang.minecraftpe`).
Движок, игровые APK и лицензия Minecraft не включены в лаунчер. Это неофициальный продукт.

## Функции
- Запуск установленной игры, определение версии, ссылка на Google Play при её отсутствии.
- Свой список серверов: добавить/изменить/удалить; IPv4, IPv6, IDN и валидация порта.
  Команда `minecraft://?addExternalServer=...` отправляется только пакету Minecraft;
  добавление и подключение подтверждаются внутри игры.
- Импорт `.mcpack`, `.mcaddon`, `.mcworld` до 512 МБ через системный выбор файла.
  Непустой ZIP проверяется без распаковки. Приватная кеш-копия передаётся read-only
  content URI с ClipData/grant; результат импорта определяет сам Minecraft.
- **Библиотека версий:** собственный APK с телефона или загрузка по пользовательской
  HTTPS-ссылке; выбор, проверка SHA-256, установка через Android, удаление только копии.
- Если выбранный versionCode не установлен, «Играть» предлагает сначала установить его.
- Диагностика копируется в буфер только по явному нажатию.

## Версии Bedrock — не каталог пиратских APK
Лаунчер не предоставляет игровые файлы или готовые ссылки на них. Официального
публичного каталога старых Bedrock APK нет. Используйте собственные законно полученные
полноценные APK и доверенные прямые HTTPS-ссылки. Страницы загрузок не являются прямыми
файлами. XAPK/APKS и обязательные split APK не поддерживаются.

Один package ID Minecraft означает одну установленную версию. Для смены нужно
подтверждение установщика Android. Даунгрейд или несовпадение подписи могут быть
отклонены. Лаунчер не удаляет игру автоматически и не обходит установщик или лицензию.
**До смены версии экспортируйте/сохраните миры.**

## Загрузки и безопасность
`ApkTransfers` разрешает только HTTPS без userinfo/фрагмента, максимум 5 перенаправлений
(каждое снова проверяется, понижение до HTTP запрещено), таймауты 15 с, до 1,5 ГБ.
Копирование проверяет заявленный размер, свободное место и считает SHA-256. Если пользователь
задал ожидаемый хеш, файл сохраняется только при совпадении. Есть прогресс и отмена.

`VersionRepository` парсит package info на worker-потоке: ожидает `com.mojang.minecraftpe`,
подписанный APK, поддерживаемые minSdk/ABI, без split-обязательств. При установленном
Minecraft сертификат APK сопоставляется с текущими/историческими сертификатами игры.
**При отсутствии доверенной установленной игры издатель не подтверждён**: одно имя пакета
и наличие подписи не доказывают подлинность. Последняя проверка и согласие — у Android.
SHA-256 и метаданные повторно проверяются перед отправкой установщику.

Библиотека и JSON-описания хранятся в `files/versions/`; выбранная версия — в
SharedPreferences. Сначала пишется `.pending.apk`, затем проверяются пакет/подпись,
после чего атомарно сохраняются APK и метаданные. Проверенные дубликаты не размножаются;
отменённые/ошибочные промежуточные файлы удаляются. Процессный death/закрытие приложения
останавливает загрузку; фонового сервиса и побайтовой докачки нет. Сеть по запросу,
без аналитики, аккаунтов или скрытого каталога. Ссылки с query-токенами не сохраняются.

FileProvider открыт только на `cache/imports` и `files/versions`, не экспортирован;
доступ выдаётся временно для чтения. Внешний исходный файл не меняется. Приватный кеш
импортов старше 7 дней очищается при следующем импорте. APK-библиотека сохраняется до
ручного удаления/удаления лаунчера. Backup выключен. Новые разрешения 1.1: INTERNET
(пользовательская загрузка) и REQUEST_INSTALL_PACKAGES (подтверждаемая системная установка).
Это development-сборка для sideload, не утверждение о соответствии правилам Google Play.

## Сборка
JDK 17, Android SDK 34, Gradle 8.9:

```sh
cd bedrock
gradle :app:testDebugUnitTest :app:assembleDebug
```

Android 7.0+, package ID `com.arena.bedrock`, versionCode 2. Обновляет Bedrock Launcher
1.0, а не прежний JavaLauncher. Подпись: открытый `../android/debug.keystore` —
**development key, не production-подпись**. APK: `app/build/outputs/apk/debug/app-debug.apk`.
CI: `.github/workflows/bedrock-apk.yml`, релиз `bedrock-launcher-1.1`.

## Тесты
- JVM: серверы, имена/MIME импортов, HTTPS URL/хеш, копирование, отмена и нехватка места.
- Android smoke: лаунчер без Minecraft показывает понятное сообщение.
- Android instrumentation: запуск, deep link, сохранение серверов/recreation,
  cross-UID чтение content URI; добавление APK, дубликаты, сохранение выбора, tampering,
  отказ не-APK, передача Installer Intent только после подтверждения.
- Для APK-тестов CI собирает `testgame/` и копирует его в **androidTest assets**, не в
  основное приложение. Модуль — приёмник Intent с package ID Minecraft только для чистого
  эмулятора. Он не игра, не публикуется и не должен устанавливаться на личный телефон.
- Тест импорта/добавления APK подаёт результат выбора документа напрямую; системный
  DocumentsUI не автоматизируется. Installer Intent перехватывается Espresso, реальная
  установка и настройки неизвестных источников не проходят автоматически.

Настоящий Bedrock, смена реальных игровых версий, миры, GPU телефона и загрузка реальных
игровых APK с внешних серверов не протестированы. Контрактные тесты этого не гарантируют.
