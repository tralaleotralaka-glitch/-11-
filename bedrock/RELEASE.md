# Bedrock Launcher 1.0 для Android

Новый нативный лаунчер с нуля — **без Java/Pojav и Windows-оболочки**.

## Скачать
**BedrockLauncher-1.0.apk**, Android 7.0+. Устанавливается отдельным приложением
с иконкой B, не заменяет предыдущий Java Launcher.

## Что работает в лаунчере
- Кнопка «Играть в Bedrock» и определение установленной версии Minecraft.
- Список серверов: сохранение, редактирование, удаление; передача адреса в игру.
- Импорт `.mcpack`, `.mcaddon`, `.mcworld` через системный выбор файла (до 512 МБ).
- Понятные ошибки и копирование диагностики.

**Как согласовано: лаунчер открывает установленный Minecraft Bedrock отдельным
приложением. Он НЕ содержит и НЕ встраивает движок Minecraft.** Игра устанавливается
отдельно; копия игры и лицензия не входят в этот APK. Если игры нет, предлагается
открыть её страницу Google Play.

Сервер нужно подтвердить в Minecraft. Результат импорта мира/пака также показывает
Minecraft, а не лаунчер. Совместимость зависит от версии игры и самих файлов.

## Что проверено автоматическими тестами
- Валидация адресов, портов, имён файлов, кодирование URI.
- Запуск лаунчера и поведение без установленной игры на Android-эмуляторе.
- Запуск и передача сервера/файла другому UID через CI-only тестовый приёмник Intent.
  Он не является Minecraft, не включён в APK и не публикуется.

**Реальный Bedrock и игровой процесс на телефоне ещё не проверены.** Контрактные
тесты не гарантируют обработку импорта каждой версией Minecraft.

Исходники: `BedrockLauncher-1.0-sources.zip`. SHA-256 APK — отдельный файл `.sha256`.
Сборка подписана открытым ключом разработки, не production-ключом.
