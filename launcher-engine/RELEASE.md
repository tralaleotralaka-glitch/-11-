# Java Launcher 0.5 — без промежуточного экрана

Лаунчер сразу открывает встроенное меню аккаунта, выбора версии и запуска игры.
Экран 0.4 с кнопкой «Открыть игровое меню» полностью удалён из APK.
**PojavLauncher отдельным приложением устанавливать не нужно.**

Это производная сборка открытого Pojav-движка, не независимо написанный JVM/renderer.
Java 8/17/21, графические библиотеки и сенсорное управление находятся в том же APK.
Меню и игра используют один application ID `com.arena.win11`. Игра работает в
отдельном процессе этого же приложения — это не переход в чужой лаунчер или Bedrock.

## Установка и запуск
1. Скачайте **JavaLauncher-0.5.apk**, установите поверх версии 0.4. Android 7.0+.
2. Откройте Java Launcher. При первом запуске дождитесь распаковки Java.
3. Выберите аккаунт и профиль. Для первой проверки рекомендуется **Vanilla 1.12.2 /
   Java 8 / GL4ES**, без модов.
4. Нажмите «Играть», дождитесь загрузки игровых файлов. Меню сменится игровым экраном
   внутри этого же приложения. Нужны интернет и несколько гигабайт свободного места.

Версия 0.5 сохраняет package ID, ключ подписи и игровые каталоги версии 0.4.
Файлы Minecraft не включены в APK. Локальный профиль не является лицензией;
upstream-проверки авторизации не отключались.

## Проверки
- Unit-тесты: один внутренний launcher entry, отсутствие старого HomeActivity,
  сохранение игрового Activity и процесса, подписи, package ID, runtime и защиты путей.
- Компиляция Java/JNI; проверка Java-бандлов, GL4ES, LWJGL для ARM32/64, x86/64.
- Android x86_64 smoke-тест: на эмуляторе нет других установленных Pojav-приложений;
  запуск по иконке приводит в меню игры под пакетом `com.arena.win11`; Java 8 распакована.

**Запуск мира Minecraft и совместимость с GPU физического ARM-телефона не проверены.**
Все версии и моды не гарантируются. Это экспериментальная сборка архивированного
upstream `gladiolus`, а не обещание поддержки актуальных версий игры.
