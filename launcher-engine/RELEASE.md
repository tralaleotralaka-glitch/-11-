# Java Launcher 0.4 — интеграция игрового движка

**Это производная сборка PojavLauncher с собственным стартовым экраном**, а не новый
самостоятельно написанный движок. В отличие от прототипа 0.3, в APK включён игровой
тракт: Android Java runtime 8/17/21, JNI-мосты, GL4ES и сенсорное управление.

## Установка и запуск
1. Скачайте **JavaLauncher-0.4.apk**. Android 7.0+, требуется свободное место для
   распаковки Java и игры (объём зависит от версии; желательно несколько гигабайт).
2. Можно установить поверх прежнего APK этого проекта; старый загрузчик заменится.
3. Нажмите **«Открыть игровое меню»** и дождитесь распаковки Java.
4. Выберите аккаунт и профиль версии. Впервые рекомендуется **Vanilla 1.12.2 / Java 8 /
   GL4ES**, без модов. Профиль Vanilla 1.12.2 добавлен по умолчанию.
5. Нажмите «Играть», дождитесь загрузки файлов игры. Сенсорные кнопки предоставляет движок.

Для авторизованных серверов и Microsoft-профиля требуется собственная лицензия.
Локальный профиль не является лицензией. Проверки движка не отключались.
Minecraft и его игровые файлы в APK не включены.

## Что проверяет сборка
- Тесты применения собственного стартового экрана к закреплённым исходникам движка.
- Компиляция Java и нативных JNI-мостов.
- Наличие Java-бандлов, GL4ES, LWJGL и JNI для ARM32/64, x86/64.
- Smoke-тест Android x86_64: открытие стартового экрана и меню движка, распаковка Java 8.

**Запуск мира Minecraft, ARM-телефон и совместимость GPU не проверены.** Работа всех
версий Minecraft не гарантируется; новые версии могут требовать более нового движка.
Это экспериментальная сборка на архивированном upstream `gladiolus`.

Исходники: **JavaLauncher-0.4-sources.zip** (движок + наши изменения и инструкции).
